# 🎙️ Say Stuff — Голосовой ввод для Mac

Зажмите кнопку, говорите, отпустите — ваши слова мгновенно появятся там, где вы печатаете.

Интернет не нужен. Всё работает локально на вашем Mac.

---

## ⚡ Быстрая установка (Рекомендуется)

**Откройте программу Terminal** (найдите в Программы → Утилиты → Terminal) и вставьте эти команды:

```bash
# Скачать Say Stuff
git clone https://github.com/enqam/say-stuff.git ~/say-stuff
cd ~/say-stuff

# Запустить установщик
chmod +x install.sh
./install.sh
```

Установщик проведёт вас через все шаги. Просто следуйте инструкциям!

---

## 🎮 Как пользоваться

После установки:

1. **Кликните туда, где можно печатать** (мессенджер, почта, документ и т.д.)
2. **Зажмите** `⌥⌘V` (Option + Command + V) на клавиатуре
3. **Говорите**, пока держите клавиши
4. **Отпустите** — ваши слова появятся!

### Горячие клавиши

| Клавиши | Что делает |
|---------|------------|
| `⌥⌘V` | Запись → Автоопределение языка |
| `⌥⌘E` | Запись → Только английский |
| `⌥⌘C` | Запись → Только русский |

### Визуальные подсказки

| Иконка | Значение |
|--------|----------|
| ⏳ Arming mic | Подготовка... |
| 🎙️ Recording | Говорите! |
| ⏳ Transcribing | Обработка речи... |
| ✅ Dictation pasted | Готово! Текст вставлен |

## 🔧 Выбор модели

При установке вы выберете модель ИИ. Большие модели = лучше точность, но требуют больше памяти.

| Модель | Размер | Нужно RAM | Для кого |
|--------|--------|-----------|----------|
| `large-v3-turbo` | 1.6 ГБ | 16+ ГБ | **Лучшее качество** — рекомендуется для современных Mac |
| `medium` | 1.5 ГБ | 8+ ГБ | Отличный баланс качества и скорости |
| `small` | 466 МБ | 4+ ГБ | Быстро, хорошая точность |
| `base` | 142 МБ | 2+ ГБ | Очень быстро, базовая точность |

### Как сменить модель позже

1. Скачайте новую модель:
   ```bash
   cd ~/whisper.cpp/models
   ./download-ggml-model.sh medium
   ```

2. Откройте файл настроек:
   ```bash
   open -e ~/.hammerspoon/init.lua
   ```

3. Найдите эту строку и измените название модели:
   ```lua
   local model = os.getenv("HOME") .. "/whisper.cpp/models/ggml-large-v3-turbo.bin"
   ```
   Замените `large-v3-turbo` на вашу новую модель (например, `medium`).

4. Перезагрузите Hammerspoon (нажмите на его иконку в меню → Reload Config)

## 🛠️ Решение проблем

### Ошибка "No audio captured"
- **Проверьте микрофон** в Системные настройки → Звук → Вход
- **Дайте доступ к микрофону**: Системные настройки → Конфиденциальность и безопасность → Микрофон → Включите Hammerspoon

### Ничего не происходит при нажатии клавиш
- **Откройте Hammerspoon** из Программ
- **Дайте доступ к управлению**: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → Включите Hammerspoon
- **Перезагрузите настройки**: Иконка Hammerspoon в меню → Reload Config

### Текст появляется не в том окне
- Убедитесь, что окно, куда нужен текст, **активно** (кликните на него) перед тем как отпустить клавиши

### Медленная транскрипция
- Попробуйте модель поменьше (см. "Выбор модели" выше)
- Закройте тяжёлые программы, чтобы освободить память

## 📋 Что устанавливается

Установщик настраивает:

- **Homebrew** — менеджер пакетов для Mac (если ещё не установлен)
- **ffmpeg** — записывает звук с микрофона
- **Hammerspoon** — отслеживает нажатия горячих клавиш
- **whisper.cpp** — ИИ, который преобразует речь в текст (работает на GPU вашего Mac)

Всё работает **100% локально** — ваш голос никуда не отправляется.

## 🗑️ Удаление

Чтобы удалить всё:

```bash
# Удалить скрипт
rm -rf ~/.hammerspoon

# Удалить whisper.cpp
rm -rf ~/whisper.cpp

# Удалить Hammerspoon (по желанию)
brew uninstall --cask hammerspoon

# Удалить ffmpeg (по желанию)
brew uninstall ffmpeg
```
