# SayStuff

SayStuff — это меню-бар приложение для macOS, которое делает локальную транскрибацию речи. Удерживайте горячую клавишу для записи, отпустите — текст будет распознан и вставлен в активное приложение.

## Требования

- macOS 13+
- `whisper-cli` из whisper.cpp (или совместимая сборка)
- Хотя бы одна модель Whisper (.bin)

## Установка (Рекомендуется для нетехнических пользователей)

1. Скачайте последний `SayStuff-<version>.dmg` из GitHub Releases.
2. Откройте DMG и перетащите SayStuff в `/Applications`.
3. При первом запуске, если macOS предупреждает о неизвестном разработчике:
   - Клик правой кнопкой по SayStuff в `/Applications` → `Open` → `Open`.

## Установка (Сборка из исходников)

1. Откройте `SayStuff.xcodeproj` в Xcode.
2. Соберите и запустите приложение.

## Настройка

1. Откройте иконку SayStuff в меню, затем Settings.
2. На вкладке Model укажите путь к `whisper-cli` и директорию моделей.
3. Скачайте модель в приложении или положите файл `.bin` в директорию моделей.
4. Дайте разрешения:
   - Доступ к микрофону (для записи)
   - Универсальный доступ (для глобальной горячей клавиши и вставки)

## Использование

- Удерживайте горячую клавишу (по умолчанию: Option+Command+V) для записи.
- Во время записи появляется красная рамка вокруг экрана.
- Отпустите клавиши — начнется транскрибация и вставка текста.

## Решение проблем

- Нет звука: проверьте System Settings > Sound > Input и доступ к микрофону.
- Горячая клавиша не работает: дайте доступ в Accessibility для SayStuff.
- `whisper-cli` не найден: укажите правильный путь в Settings.
